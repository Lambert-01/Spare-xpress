# Spare Xpress Ltd. - Automotive Spare Parts E-Commerce Platform

## Project Overview
**Spare Xpress** is a comprehensive web-based e-commerce platform designed to modernize the automotive spare parts industry in Rwanda. It serves as a centralized marketplace connecting customers (both individual car owners and professional mechanics) with quality auto parts through an intuitive and feature-rich interface.

## Key Features & Functionality

### Frontend E-Commerce Experience
- **Dynamic Product Search & Filtering**: Cascading brand → model → year → category filters with real-time results
- **Responsive Design**: Mobile-first approach with glassmorphic UI and smooth animations
- **Shopping Cart & Checkout**: Secure, asynchronous cart management with real-time updates
- **User Accounts**: Registration, login, order history, and profile management
- **Product Management**: Detailed product pages with specifications, compatibility information, and image galleries
- **Wishlist & Order Requests**: Save favorite products and request custom orders

### Backend Administration
- **Comprehensive Dashboard**: Real-time analytics, low stock alerts, and sales reporting
- **Inventory Management**: Full CRUD operations for products, brands, models, and categories
- **Order Processing**: Track orders through all stages (pending → processing → shipped → delivered)
- **Customer Management**: View customer details, order history, and communication
- **Notifications System**: Real-time alerts for new orders, price requests, and customer messages
- **Data Export**: Export inventory and sales data as CSV/Excel files

### Technical Highlights
- **Architecture**: MVC pattern with clear separation between frontend, API, and admin backend
- **Database**: MySQL with normalized schema for efficient data management
- **Security**: PDO prepared statements, bcrypt password hashing, and session validation
- **Email System**: PHPMailer integration for transactional emails and notifications
- **Invoicing**: Automated PDF/HTML invoice generation with professional layouts
- **API**: RESTful endpoints for asynchronous frontend interactions

## Technology Stack
- **Backend**: PHP 8.x
- **Database**: MySQL/MariaDB
- **Frontend**: HTML5, CSS3 (SCSS), JavaScript (Vanilla), Bootstrap 5
- **Dependencies**: Composer, PHPMailer, Font Awesome
- **Development**: Local server via PHP built-in server
